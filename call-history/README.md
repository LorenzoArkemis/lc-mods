# call-history

A Claude Code mod that keeps a running list of every tool call, skill and slash
command in the current session, shown in a side pane. Each row is one call;
click it to see the command it ran.

```
▸ 14:02:11 ✓ Bash
▾ 14:02:15 ✓ Bash
    ls -la ~/.claude/mods
▸ 14:02:20 ✗ Read
▸ 14:02:31 ✓ skill:dataviz
▸ 14:02:40 ✓ /usage-pane
```

## Install

The mod is loaded from its folder through `CLAUDE_CODE_PLUGIN_DIRS` in
`~/.claude/settings.json` (paths separated by `:`):

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/workspace/lc-mods/usage:~/workspace/lc-mods/call-history"
  }
}
```

The setting is read when a session starts, so restart Claude Code after adding
it. While a session runs, saving a file in the folder reloads the mod.

For a single session instead: `claude --plugin-dir ~/workspace/lc-mods/call-history`.

## Use

| Command | What it does |
| --- | --- |
| `/calls` | Opens the Call history pane |
| `/calls clear` | Empties the history |

The pane does not open by itself. Click a row, or focus it and press Enter, to
expand it; click again to fold it.

## What a row shows

**Compact:** time, status, and the name.

| Mark | Status |
| --- | --- |
| `…` yellow | running |
| `✓` green | succeeded |
| `✗` red | the tool reported an error |
| `⊘` dim | denied (by you, a permission rule or a hook) |

- Tool calls show the tool: `Bash`, `Read`, `mcp__…`.
- Skill calls show `skill:<name>`. Skills and slash commands are drawn in bold cyan.
- Slash commands you type show `/<name>`, including skills run as `/<name>`.
- `↳` marks a call made inside a subagent.

**Expanded:** only the command, as given, up to 12 lines:

| Call | Shown |
| --- | --- |
| Bash | the command |
| Read, Edit, Write | the file path |
| NotebookEdit | the notebook path |
| Grep, Glob | the pattern |
| Agent | the task description |
| WebFetch / WebSearch | the URL / the query |
| Skill | the args passed to the skill |
| Slash command | `/name args` |
| Any other tool | its arguments as JSON |

Outputs are not recorded; the transcript has them.

## Colors

The pane uses only the terminal's ANSI colors (green, red, yellow, cyan), dim
and bold, so it follows your terminal theme rather than Claude Code's.

## Limits

- Keeps the last 200 calls of the current session. History survives a reload of
  the mod but not a new session.
- A stored command is cut at 2,000 characters.
- The pane draws as many rows as fit its height, counting entries rather than
  screen lines, so several expanded rows can overflow it.
- Recording never blocks a call: if the mod's hook fails, the call goes on.

## Files

| Path | Purpose |
| --- | --- |
| `.claude-plugin/plugin.json` | Manifest |
| `hooks/hooks.json` | Names the hooks module |
| `hooks/register.tsx` | The mod: recorders, `/calls`, the pane |
| `types/index.d.ts` | The `Call` type and the session state it keeps |
| `tests/history.test.tsx` | Behaviour tests |
| `.claude-plugin/types/` | Generated by Claude Code on load; not edited |

## How it works

- `tool.call` hook: records a `running` entry before the tool runs, then marks it
  `ok`, `error` or `denied` from the result.
- `command.run` hook: does the same for typed slash commands; a second hook on
  `calls` answers the mod's own command.
- State lives in two session atoms: `calls` (the entries, shape tag `calls-3`)
  and `expanded` (ids of open rows). Changing the `Call` fields means bumping
  the shape tag so older entries are dropped instead of drawn half-filled.
- `ui.render` on the `call-history` pane draws each entry as a plain `Button`
  whose press toggles its id in `expanded`.

## Develop

```sh
cd ~/workspace/lc-mods/call-history
claude plugin validate .   # manifest and hooks as the engine reads them
npx -p typescript tsc -p . # type-check (types appear after the first load)
claude plugin test .       # runs tests/*.test.tsx
```
