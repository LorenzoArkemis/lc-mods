# usage

A Claude Code mod that keeps the session's usage in the status line: how full
the context window is, how much of each rate-limit window is used and when it
resets, and what the session has cost so far.

```
ctx 42% 84k/200k · 5h 13% ↻2h10m · 7d 71%! ↻3d4h · $1.23
```

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install usage --marketplace LorenzoArkemis/lc-mods
```

Answer `y` to add the marketplace, then pick a scope (user is first). From a
shell instead:

```sh
claude plugin install usage --marketplace LorenzoArkemis/lc-mods
```

In the desktop app, where `/plugin` does not run: click + next to the prompt
box, then Plugins, Add marketplace with `LorenzoArkemis/lc-mods`, then Add plugin.

## What the line shows

| Part | Meaning |
| --- | --- |
| `ctx 42% 84k/200k` | Context window used, as a share and in tokens. `ctx –` until the first response |
| `5h 13% ↻2h10m` | The 5-hour rate-limit window: share used, time until it resets |
| `7d 71%! ↻3d4h` | The 7-day window, the same way |
| `spend …` | A spend limit, when your plan has one |
| `$1.23` | The session's cost, when it is tracked |

A `!` after a figure means 70% or more; `!!` means 90% or more. Rate-limit
windows appear only once Claude Code has reported them.

The line refreshes after every response, and the reset countdowns tick every
minute in between. It has no colors: the status line is plain text, so it reads
the same in any terminal theme.

## Files

| Path | Purpose |
| --- | --- |
| `.claude-plugin/plugin.json` | Manifest |
| `hooks/hooks.json` | Names the hooks module |
| `hooks/register.tsx` | The mod |
| `types/index.d.ts` | The `Usage` type and the session state it keeps |
| `.claude-plugin/types/` | Generated by Claude Code on load; not edited |

## How it works

- `session.start` reads `$.session.usage()`, writes the line with
  `$.ui.status`, and starts a one-minute timer for the countdowns.
- `session.measure` fires when the engine measures usage again (after each
  response) and rewrites the line.
- The last measurement is kept in a session atom (`usage.last`), so the line
  survives a reload of the mod.

```sh
claude --plugin-dir ~/workspace/lc-mods/usage

```
